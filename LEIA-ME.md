# Aplicação PHP do portal ZEUS TECH (ISO/IEC 17020)

Ramo separado do sítio estático. Não é servido pelo GitHub Pages.

Instala-se em `/home/contine1/zeus_publico/`. Os documentos ficam FORA desta
pasta, em `/home/contine1/zeus_documentos/`, e só se abrem pelo `doc.php`, que
exige sessão iniciada.

O `_config.php` **não está aqui de propósito**: contém a senha da base de dados
e escreve-se directamente no servidor.
